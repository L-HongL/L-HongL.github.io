欧拉回路：假设有一个图，如果能从一个点出发，一次性不重复通过所有边，及图存在欧拉回路。

欧拉回路首先是一个强连通图，然后再通过一下特性判断：
1.如果图是无向图，则所有点的度为偶数时，存在欧拉回路。或者有两个点度为奇数时，存在以一个点为起点，另一个点为终点的欧拉回路。
度为偶数的点，可以通过走包含两条度的回路重置点的位置，如果度为奇数，那么这个点在最后一条路，无法再重置回这个点，要么永远走出这个点，要么以这个点为终点不在走。

2.如果图是有向图，则以出度为-1，入度为1，所有点度为0时，存在欧拉回路。如果存在两个点，一个点为1，另一个点为-1，则-1为起点，1为终点。证明结果类似1.

如何输出欧拉回路？
通过一下函数

void output_euler(int x,int las){//x为当前节点，las为上一个节点
    for(auto v:a[x]){
        if(v==las)continue;
        dfs(v,x);
        cout<<v<<" "<<x;//这里是dfs倒序输出
    }
}
之所以要倒序输出，是因为如果存在奇点，dfs回走到死路却未遍历完所有点，所以以死路走到的点出发，走回这个点，然后从这个点另一条回路进入整个回路
